# GitPolis — Living 3D Procedural Metropolis from ANY GitHub Profile

**GitPolis** transforms any GitHub username into a living, interactive, procedural 3D coastal metropolis. Every repository, language, star, fork, commit history, and public activity metric gives that city its own unique architectural identity.

Two developers in the same domain will get completely distinct cities based on their actual lines of code, commit cadences, documentation completeness, release milestones, and community prestige.

---

## ⚡ Quick Start

From the root workspace directory (`GitPolis`):

1. **Install dependencies**:
   ```bash
   npm run install:app
   ```
2. **Start the dev server**:
   ```bash
   npm run dev
   ```
3. **Open in your browser**:
   ```
   http://localhost:5173
   ```

*(You can also pass `?user=<username>` in the URL to immediately generate a specific city, e.g. `http://localhost:5173/?user=torvalds` or `http://localhost:5173/?user=gaearon`).*

## 🏗️ The 5-Phase Municipal Construction Sequence

When you enter any GitHub username, GitPolis displays an intuitive, real-time visual construction sequence:

1. **Surveying Profile & Satellites** — Querying GitHub public profile, followers, avatar, and repository catalog.
2. **Zoning Municipal Cadastre** — Calculating **Prosperity (0-100)** and **Fulfillment (0-100)** indices, sorting flagship projects into Downtown and emerging codebases into Midtown/Outskirts.
3. **Reclaiming Coastline & Infrastructure** — Dredging the dual-bank harbor canal, laying transit bridges, and paving avenues.
4. **Raising Architectural Skylines** — Procedural building extrusion where buildings rise floor-by-floor with construction sparks and cranes.
5. **Simulating Commuter & Urban Life** — Commuter vehicles drive across avenues, canal boats cruise the harbor, pedestrians walk the sidewalks, streetlamps illuminate at dusk, and dynamic weather adapts to commit velocity.

## 🏛️ How GitHub Stats Shape the City & District Identity

### 1. Macro Profile Level (City & Atmosphere)
- **Account Age (Years on GitHub)**: Shapes the historical depth of the city — founding stone inscription, plaza monument height, vintage masonry, and mature tree groves.
- **Followers & Following**: Dictates the grandeur of the Central Civic Plaza, civic obelisk height, celebratory banners, and harbor yacht/cruise ship density.
- **Total Stars & Codebase Volume**: Expands the metropolis radius, urban rings, and adds golden rooftop cornices.
- **Commit Velocity & Recency**: Sets the real-time **City Climate**:
  - *Active Sprint / Streak (<14 days)*: Radiant daylight or high-velocity electric data-drizzle, high commuter traffic, rotating yellow construction cranes.
  - *Steady Cadence (1-6 months)*: Warm morning breeze with bustling pedestrians.
  - *Heritage / Archival (>1 year)*: Amber twilight or quiet golden-hour harbor mist with soft lantern glow.

### 2. Repository Level (District Blocks & Architecture)
- **Urban Cadastre Zoning**:
  - Highest-prosperity and largest codebases claim prime **Downtown** slots around Central Plaza.
  - Steady active repositories form **Midtown**.
  - Lightweight utilities and emerging projects form the organic **Outskirts**.
- **Prosperity Index (0-100)** *(Calculated from stars, forks, watchers, releases)*:
  - *Gilded Metropolis (>=68)*: Marble curbs, rooftop observation decks, golden spires, bright aerial pinnacle beacons, and plaza fountains.
  - *Thriving Commercial (42-67)*: Polished stone, warm illuminated studio windows, and rooftop gardens.
  - *Artisan / Emerging (<42)*: Functionalist masonry or clean concrete lofts.
- **Fulfillment Index (0-100)** *(Calculated from documentation, README, license, tests, homepage, LOC)*:
  - Higher fulfillment furnishes the block with streetlamps, decorative railings, paved plazas, and landscaped trees.
- **Maintenance Health & Open Issues**:
  - Repositories with high open issues receive **active construction scaffolding**, safety netting, and blinking orange hazard beacons.
  - Zero/low issues on active projects produce pristine glass facades, gold railings, and flowering planters.
- **Release Milestones**: Repos with tagged releases gain a **Triumphal Milestone Arch** crowned with brass medallions.
- **Live Demos & GitHub Pages**: Yields a **Coastal Pier Promenade** and an illuminated live web lighthouse spire.
- **Wikis**: Adds a **Courtyard Reading Pavilion / Observatory Kiosk**.
- **Forks**: Distinct **Twin-Pillar Guild Annex Archway**.

### 3. Language & Polyglot Composition
Twelve distinct architectural styles mapped to programming languages:
- **TypeScript**: *Glass & Timber Tech Campus* — Cantilevered glazed towers, cedar louvers, and sky-gardens.
- **JavaScript**: *Sunlit Ochre & Loft Studios* — Amber brick, studio skylights, and corner balconies.
- **Python**: *Botanical Atrium & Solarium* — Limestone laboratories, verdigris copper domes, and conservatories.
- **Rust**: *Brutalist Corten Foundry* — Weathered corten steel halls, sawtooth skylights, and furnace clerestories.
- **Go**: *Nordic Skybridge Towers* — Alabaster twin towers linked by glass bridges and glacier-cyan beacons.
- **C / C++**: *Granite Civic Monoliths* — Foundational stepped granite ziggurats and bronze spires.
- **Java / C#**: *Art Deco Crown Spires* — Enterprise sandstone skyscrapers with vertical fluted pilasters.
- **Ruby / PHP**: *Artisanal Terracotta Quarter* — Terracotta pitched roofs, dormer studios, and wrought-iron balconies.
- **Swift**: *Sculpted Cupertino Pavilions* — Precision-milled ivory rings, curved glass pavilions, and citrus highlights.
- **HTML / CSS / Frontend**: *Design Canal Townhouses* — Pastel Dutch-style gabled canal houses.
- **DevOps / Shell**: *Harbor Control & Modular Works* — Operations control towers, radar arrays, and container bays.
- **Polyglot & Others**: *Scholarly Sandstone Hall* — Sandstone archive halls with hipped slate roofs.

*(Multi-language repositories receive composite hybrid blocks with secondary language wings proportional to their byte percentage!)*

### 4. Dynamic Domain Specialization
Intelligent, non-hardcoded classification that equips buildings with specialized architectural features:
- **AI / Neural Systems**: Holographic Neural Telemetry Dome & Fiber Optic Spire.
- **Systems & Cloud Infrastructure**: Modular Logistics Container Bays & Telecommunications Radar.
- **Web & Interactive Studio**: Canal Terraces, Glass Cafe Atrium & Sunlit Awnings.
- **Mobile & Touch**: Sculpted Cupertino Ivory Pavilions & Minimalist Rings.
- **Data Science & Computing**: Astronomical Observatory Dome, Solar Cell Array & Knowledge Obelisk.
- **Security & Cryptography**: Reinforced Granite Bastion & Cryptographic Vault Pylons.
- **Gaming & 3D Graphics**: Kinetic Neon Spire Sculpture & Prismatic Facade.
- **Developer Tooling & CLI**: Functionalist Brick Clocktower & Logistics Dispatch Hub.

### 5. Commit Blueprints
Every individual structure inside a block is shaped by clusters of real commits:
- `feat` commits → Central towers and residential lofts.
- `fix` commits → Structural reinforcement buttresses and maintenance housings.
- `refactor` commits → Streamlined glass skybridges.
- `docs` commits → Public reading pavilions and clock face medallions.
- `test` commits → Sentinel calibration spires.
- `release` commits → Golden celebratory pinnacle beacons.
- `init` commits → Cornerstone foundations.

## 🎮 Navigation & Interactive Controls

- **Left-Click + Drag**: Orbit 3D camera around the city.
- **Right-Click + Drag / WASD / Arrow Keys**: Pan and fly across the city.
- **Scroll Wheel**: Smooth zoom from high-altitude satellite overview to street-level sidewalks.
- **Click any Block or Building**: Smooth camera flight into that district with deep inspection of LOC, prosperity, language shares, and commit blueprints.
- **Top Bar "Directory" Button**: Full searchable Cadastre modal with filtering by Language, Domain, and sorting by Stars, LOC, Prosperity, or Recency.
- **Bottom Timeline Scrubber**: Scrub or play the chronological city growth time-lapse from the founding repo to present day.
- **Top-Right Sun / Weather Controls**: Adjust time of day (Morning, Noon, Sunset, Midnight Neon) and Weather (Clear, Mist, Data-Rain).
- **Postcard Button**: Export a high-resolution PNG postcard of your custom city with personalized typography and statistics badge.
- **API Key Button**: Optional GitHub Personal Access Token field to unlock 5,000 requests/hour rate limit for deep portfolio inspections.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons
- **3D Engine**: Three.js (WebGL, PCF Soft Shadows, ACESFilmic Tone Mapping, Procedural Textures)
- **API & Bundler**: Vite 6 with dual-mode fetching (Express/Vite server caching + direct client-side GitHub REST fallback)
